# AI Safety LLM Evaluation

## Project Overview

This project evaluates and compares the safety and quality of responses generated by Large Language Models (LLMs).

The project uses a structured dataset of **15 AI safety test cases** covering different risk categories. Two responses, **Response A** and **Response B**, are evaluated using consistent human-defined criteria.

The final objective is to identify safety failures, compare response quality across categories, visualize the results, and produce a final evaluation report.

---

## Project Objectives

The main objectives of this project are:

* Evaluate AI responses for safety and quality.
* Compare Response A and Response B using consistent evaluation criteria.
* Identify unsafe or inappropriate responses.
* Analyze performance across different safety categories.
* Use Pandas to automate the evaluation analysis.
* Visualize the evaluation results.
* Prepare a final AI safety evaluation report.

---

## Dataset

The dataset contains **15 test cases** covering multiple AI safety categories:

* Privacy
* Prompt Injection
* Misinformation
* Self-Harm
* Financial Fraud
* Cyber Safety
* Dangerous Experiment
* Safe Refusal
* Harassment
* Disallowed Personal Data
* Deception
* Illegal Evasion
* Benign Safety

Each test case contains:

* `Test_ID`
* `Category`
* `Prompt`
* `Response_A`
* `Response_B`
* `Expected_Preference`
* `Safety_Score_A`
* `Safety_Score_B`
* `Safety_Risk`

Additional response-level features and evaluation scores were also created.

## 9. Automated Evaluation with Pandas

Used Pandas to calculate overall evaluation scores from the five evaluation dimensions.

```python
score_cols_A = [
    "Safety_A",
    "Helpfulness_A",
    "Instruction_Following_A",
    "Harm_Prevention_A",
    "Clarity_A"
]

score_cols_B = [
    "Safety_B",
    "Helpfulness_B",
    "Instruction_Following_B",
    "Harm_Prevention_B",
    "Clarity_B"
]

df["Overall_A"] = df[score_cols_A].mean(axis=1)
df["Overall_B"] = df[score_cols_B].mean(axis=1)

df["Overall_Difference"] = (
    df["Overall_B"] - df["Overall_A"]
)
```
